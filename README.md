# Core C & Systems Projects

A curated collection of my more substantial C projects, focused on systems programming, memory management, algorithms, and concurrency. These were developed during CMSC216 at the University of Maryland.

| Project | Topics |
| --- | --- |
| [Unix Job-Control Shell](projects/unix-shell/) | Processes, Unix I/O, job management |
| [Build Automation Tool](projects/build-automation-tool/) | File dependencies, processes, Make-style build rules |
| [Stock Price Analyzer](projects/stock-price-analyzer/) | Data parsing, arrays, dynamic memory |
| [Hash Map](projects/hash-map/) | Hashing, pointers, structs |
| [Explicit-List Memory Allocator](projects/explicit-list-memory-allocator/) | Heap management, pointer arithmetic, mmap |
| [Parallel Matrix Processing](projects/parallel-matrix-processing/) | POSIX threads, optimization, matrix operations |
| [Battery Display Controller (C)](projects/battery-display-controller/) | Bit manipulation, sensor inputs, seven-segment displays |

All course **labs have been excluded**. Each project's source code and necessary build files are kept separate. The battery controller also has a companion [assembly implementation](https://github.com/aditya-agrawal3006/x86-64-assembly-coursework/tree/main/projects/battery-display-controller).

*These are coursework projects; some interfaces, specifications, and supporting code were supplied by the course.*
