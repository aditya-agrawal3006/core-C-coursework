# Battery Display Controller (C)

A simulated battery controller implemented in C. Reads sensor data, computes battery state, and updates a bit-encoded display using integer arithmetic and bit manipulation.

**Concepts:** C structs, bitmasks, bit shifts, input validation, seven-segment displays.

The corresponding [x86-64 assembly implementation](https://github.com/aditya-agrawal3006/x86-64-assembly-coursework/tree/main/projects/battery-display-controller) is in the assembly coursework repository.

Build on Linux with `make`; run `./batt_main`.

*Based on CMSC216 coursework. Some interfaces and simulator code were supplied by the course.*
