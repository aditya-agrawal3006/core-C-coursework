# Stock Price Analyzer

A C program that loads historical price data and evaluates price trends and potential buy/sell intervals. This is a programming exercise, not a trading strategy.

**Main concepts:** file parsing · dynamic memory · array processing

Build with `make` and run `./stock_main` on Linux.

*Source: CMSC216 Fall 2025, Project 1. Original coursework contains some instructor-provided interfaces and scaffolding.*
